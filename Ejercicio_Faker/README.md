# Ejercicio_Faker

Programa en Python que usa [Faker](https://pypi.org/project/Faker/) para crear 15 usuarios ficticios, mostrarlos por pantalla y elegir uno al azar.

```bash
git clone <URL_DEL_REPOSITORIO>
cd Ejercicio_Faker

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
python main.py
```
